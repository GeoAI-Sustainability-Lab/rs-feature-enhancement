🟦 L1 — Kernel & 卷積

6 分鐘 · 練習：5 個預設 + 自訂 kernel

📖 觀念

卷積 = 用一個小矩陣（kernel）在影像上滑動，每個位置計算 kernel 與鄰近像素的加權和。不同 kernel 提取不同特徵。

1先試 5 個預設 kernel
點按鈕逐個試：均值、Sobel-X、Sobel-Y、Laplacian、銳化。注意輸出怎麼變。
2觀察 kernel 數值
每按一個預設，下方 9 格會自動填上對應數值。注意正負分布。
均值（全正）→ 模糊；Sobel（正負對稱）→ 邊緣；中央大其餘小 → 銳化。
3挑戰：自製對角線偵測
手動填 kernel：左上 -1、右下 -1、主對角全 1、其餘 0。看效果。

🟧 L2 — 多 Kernel + Pooling

5 分鐘 · 練習：4 個 kernel 並排 + Pooling 切換

📖 觀念

真實 CNN 一層用多個 kernel 平行 → 多張 feature maps。Pooling 降解析度（Max / Avg）。輸出尺寸 = (input + 2×pad − k) / stride + 1。

1看 4 張並排 feature maps
同一張輸入，分別經過 Sobel-X / Sobel-Y / 均值 / 銳化，結果完全不同。
2玩 Pooling
下方各 4 張 feature map 通過 pooling，看尺寸變化。切換 Max / Avg / 大小 2-4。
3想想為什麼用 Max
Max Pooling 強調「該區域最強反應」(最像該特徵的位置)，Avg 則是平均強度。

🎮 互動練習

改 Pooling 設定看 4 張 feature map 即時變化。
原圖 (64×64) → 4 個 kernel → 4 張 feature map (64×64) → Pooling 後

🟪 L3 — Tiny CNN 權重傳遞

6 分鐘 · 練習：6 個樣本即時推論

📖 觀念

完整 CNN 管線：Input(8×8) → Conv(2 kernels 3×3) → ReLU → MaxPool 2×2 → Flatten → Dense(2 outputs) → 分類

1看 6 個樣本
3 個 X、3 個 O 的 8×8 二值圖。每個都即時跑過 CNN 顯示分類結果。
2調 bias 看影響
把 biasX 調很高，所有樣本都會被分類成 X（不論真實標籤）。再復原。
3理解 logit
每個樣本下方有 logit_X 和 logit_O 數值。哪個大就分到哪類。

🎮 互動練習

6 個樣本即時推論。調 bias 看哪些樣本分類會變。
分類邏輯：
logit_X = sumK1 - sumK2 + biasX
logit_O = sumK2 - sumK1 + biasO
argmax → 分類
📌 練熟後 → 去 CNN 請作答 L3 闖關

🤖 L4 — 影像分類 (MobileNet)

5 分鐘 + 模型下載 · 練習：點圖看預測 / 上傳自己的圖

📖 觀念

MobileNet 是訓練好的真實 CNN 模型，能辨識 1000 個 ImageNet 類別（動物、物品、景物）。直接在你的瀏覽器執行，不需後端。

1等模型下載

2點任一張內建圖
看 Top-5 預測。注意模型對不同場景的判斷信心。
3上傳自己的圖
從手機 / 電腦選一張照片（風景、寵物、物品都行）看 MobileNet 怎麼分類。

🎯 L5 — 物件偵測 (COCO-SSD)

6 分鐘 + 模型下載 · 練習：偵測 80 類物件 + IoU 計算

📖 觀念

COCO-SSD 不只說「圖中有什麼」，還要框出位置 (bounding box) + 類別 + 信心。能識別 80 類常見物件（人、車、動物、傢俱…）。

IoU (Intersection over Union) = 交集 / 聯集 = 兩框重疊度。0=不重疊、1=完全重疊。常用 0.5 為「成功偵測」門檻。

1點內建圖或上傳
看模型畫出 bbox + 標籤。試試多物件的圖。
2調信心門檻
門檻 0 → 顯示所有偵測（含很雜的）；0.5 → 中庸；0.9 → 只顯示最確定的。
3玩 IoU 計算器
下方拖兩個框（藍 = GT、橘 = 預測），看 IoU 即時變化。讓兩框完全重疊試試。

🎨 L6 — 影像分割 (BodyPix)

5 分鐘 + 模型下載 · 練習：人像語義分割 + 實例概念

📖 觀念

影像分割：把每一個像素都分類，不只框出物件。

  • 語義分割 (Semantic)：每像素一個類別。三隻狗的所有像素都標 "dog"。
  • 實例分割 (Instance)：每像素一個「物件實例」。三隻狗會被標 "dog#1, dog#2, dog#3"。

本練習用 BodyPix（專注於「人 vs 背景」+ 24 個身體部位）。

1等模型下載
~5 MB 的 BodyPix 模型。等顯示完成。
2上傳一張人像照片
最好是含 1-2 個人的清晰照片（手機自拍、合照都行）。
3切換顯示模式
人/背景遮罩 → 身體部位 (24 種顏色) → 半透明蓋圖。
4理解「語義 vs 實例」
注意：BodyPix 只做「人 vs 背景」的語義分割。要區分多人實例需要更大的模型（Mask R-CNN）。
