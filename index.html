📖 老師部署教學

  1. 打開 Google 試算表 → 上方功能表 擴充功能 → Apps Script
  2. 已自動準備好「RS_FeatureEnhancement_Quest」專案，程式碼已貼好
  3. 右上角點 部署 → 新增部署作業
  4. 類型選 網頁應用程式
  5. 說明任填、執行身分：我（你的 email）、存取權：任何人
  6. 按「部署」→ 跳出授權視窗 → 選你的帳號 → 進階 → 前往 RS_FeatureEnhancement_Quest（不安全） → 允許
  7. 複製給出的 網頁應用程式 URL
  8. 貼回上方「Web App URL」欄位 → 按儲存
⚠️ 第一次「進階 → 允許」是必要的，因為 Apps Script 需要存取你的試算表權限。完成後 URL 就可以給全班用。
